# HyDRA version 1.0

Code and data of the High-Resolution Water Resources Assessment model (HyDRA) version 1.0, which estimates industrial
and domestic water withdrawal and consumption on a 3 arcsec grid for the six Gulf Cooperation Council countries and
Jordan, 1990–2025.

Al-Zu'bi, A. and Wada, Y.: A High-Resolution Water Resources Assessment Model (HyDRA version 1.0) for Industrial and
Domestic Water Use: A regional application for the Gulf Cooperation Council (GCC) Countries, Geoscientific Model
Development (in review), egusphere-2026-3475.


## Contents

| Folder | Content | Paper |
|---|---|---|
| `Industrial_Sector/` | Industrial and power-plant water use model, its inputs and the TEF calculator | Sect. 2.1, Tables 3 and S1 |
| `Industrial_Sector/Sub_Sectors/` | Production series and plant capacities and locations, by subsector | Table S1 |
| `Industrial_Sector/TEF_Calculator/` | Techno-economic factor (TEF) for every country and year | Eq. 3, Sect. 3.1.1 |
| `Industrial_Sector/Validation/` | Derivation of the baseline withdrawal intensities from national statistics | Table 3, Sect. 2.1 |
| `Domestic_Sector/` | Domestic water use model, its data set and the uncertainty analysis | Sect. 2.2 |

Each of the two sector folders has its own README with the order in which the scripts are run, the input files and the
outputs.
